# slide-pack — 문서를 발표 슬라이드로 바꿔주는 AI 스킬

**기획서, 프롬프트, 회의록 같은 마크다운 문서를 넣으면, 브라우저에서 바로 열리는 슬라이드 덱(HTML 파일 1개)이 나옵니다.**

- 파워포인트가 필요 없습니다. 나온 HTML 파일을 더블클릭하면 바로 발표 화면이 뜹니다.
- 파일 하나가 전부라서 공용 드라이브·메일·메신저로 그냥 전달하면 됩니다. 인터넷이 안 되는 곳에서도 열립니다.
- 슬라이드 넘기기: **← → 방향키, 스페이스바, 또는 화면 클릭**

> 처음이시라면 이 문서만 위에서부터 순서대로 읽으면 됩니다. 5분이면 충분합니다.

---

## 🚀 3분 만에 시작하기

**1단계.** 슬라이드로 만들고 싶은 문서를 준비합니다. (예: `agent-plan.md` — 팀 에이전트 기획서)

**2단계.** AI 코치(이노허브/Codex)에게 이 저장소 폴더를 열어둔 상태로 이렇게 말합니다:

```
agent-plan.md를 slide-pack으로 슬라이드 덱 만들어줘
```

**3단계.** 끝입니다. 원문과 같은 폴더에 `agent-plan-deck.html`이 생깁니다. 더블클릭해서 열어보세요.

> 💡 실제로 어떤 결과가 나오는지 미리 보고 싶다면
> [`examples/sample/`](examples/sample/) 폴더를 보세요.
> 입력 문서(`agent-plan.md`)와 출력 슬라이드(`agent-plan-deck.html`)가 쌍으로 들어 있습니다.

---

## 🎨 테마는 2가지 — 언제 무엇을 쓰나요?

| | 기본 테마 (다크) | SK CI 테마 (라이트) |
|---|---|---|
| **생김새** | 어두운 배경, 차분한 톤 | 흰 배경 + SK 레드/오렌지 포인트 |
| **언제** | 팀 내부에서 빠르게 훑을 때 | 발표·보고 등 남에게 보여줄 때 |
| **예시 파일** | [`examples/lv5-packaging-deck.html`](examples/lv5-packaging-deck.html) | [`examples/lv5-presentation-deck-sk.html`](examples/lv5-presentation-deck-sk.html) |
| **호출 방법** | 그냥 요청하면 기본 적용 | 아래 문장으로 요청 |

SK CI 테마로 만들려면:

```
agent-plan.md를 slide-pack SK CI 테마로 발표용 덱 만들어줘.
DESIGN.md의 토큰만 사용하고, template-sk-ci.html 스켈레톤을 써.
```

발표용(SK CI)으로 만들면 세 가지가 추가로 적용됩니다:

1. **제목이 주장이 됩니다** — "데이터 구조" 같은 밋밋한 제목 대신 "사람은 검증 지점에서만 개입한다"처럼 청중이 기억할 한 문장으로.
2. **섹션 구분 슬라이드** — 내용이 3부 이상이면 빨간 배경의 파트 전환 슬라이드가 들어갑니다.
3. **역할 분담과 원문 안내** — 첫 장에 발표/데모/Q&A 담당, 마지막 장에 원문 위치가 들어갑니다.

## 📄 어떤 문서를 넣으면 좋은가요?

| 넣는 문서 | 추천 테마 | 이렇게 나옵니다 |
|---|---|---|
| 에이전트 기획서 (agent-plan.md) | 발표용(SK CI) | 문제 → 해결 → 데모 → 배운 것, 4부 구성 |
| 교육 자료·프롬프트 문서 | 기본(다크) | 섹션당 1장, 표 중심 요약 |
| 체크리스트·테스트 결과 | 기본(다크) | 항목별 불릿, 결과 ✅/❌ 표시 |
| 데모 시나리오 대본 | 발표용(SK CI) | "라이브 데모" 구분 슬라이드 중심, 슬라이드 최소 |

## 📁 이 저장소에 뭐가 들어있나요?

```
Jcurve_SKI/
├── README.md            ← 지금 읽고 있는 문서
├── SKILL.md             ← AI가 읽는 스킬 정의 (변환 규칙·절차)
├── DESIGN.md            ← SK CI 색·폰트 규칙 (디자인의 원본)
├── assets/
│   ├── template.html            ← 기본 다크 테마 뼈대
│   └── template-sk-ci.html      ← SK CI 발표용 테마 뼈대
└── examples/
    ├── lv5-packaging-deck.html          ← 기본 테마 완성 예시
    ├── lv5-presentation-deck-sk.html    ← SK CI 테마 완성 예시
    └── sample/
        ├── agent-plan.md                ← 입력 예시 (가상 구매기획팀 기획서)
        └── agent-plan-deck.html         ← 출력 예시 (위 문서로 만든 덱)
```

각 파일은 역할이 하나씩입니다. **사람은 README만 읽으면 되고, AI는 SKILL.md와 DESIGN.md를 읽습니다.**

## 🏢 회사 색(CI)을 바꾸고 싶다면

색과 폰트의 **원본은 `DESIGN.md` 한 파일**입니다. 슬라이드 파일을 직접 고치지 마세요.

1. 사내 브랜드 가이드라인에서 공식 색상값(hex 코드)을 확인합니다.
2. `DESIGN.md`의 **"2. 컬러 팔레트" 표의 값만** 바꿉니다.
3. `assets/template-sk-ci.html` 상단 `:root`의 같은 토큰에도 반영합니다.
4. 이후 새로 만드는 모든 덱에 자동 적용됩니다. 이미 만든 덱은 다시 생성하면 됩니다.

> 현재 들어있는 SK 레드(#EA002C)·오렌지(#F47725)는 공개 자료 기반 근사치입니다.
> 공식 값을 확보하면 위 절차대로 교체하세요.

---

## ✅ 잘 만들어졌는지 확인하는 법

만들어진 덱은 다음 5가지를 만족해야 합니다. AI에게 "검증해줘"라고 하면 자동으로 점검합니다.

- [ ] 외부 인터넷 요청이 0건인가 (오프라인에서도 열리는가)
- [ ] 슬라이드가 10장 이하인가
- [ ] 슬라이드당 불릿 5개·표 6행을 넘지 않는가
- [ ] 마지막 슬라이드에 원문 위치가 적혀 있는가
- [ ] 파일 이름이 `원문이름-deck.html` 규칙을 따르는가

## ❓ 자주 묻는 질문

**Q. 슬라이드 내용을 조금 고치고 싶어요. HTML을 직접 수정해도 되나요?**
안 됩니다. 슬라이드는 요약본이고 **원문 문서가 원본(SSOT)** 입니다. 원문을 고친 뒤 "덱 다시 만들어줘"라고 하세요. HTML을 직접 고치면 다음 재생성 때 수정이 사라집니다.

**Q. 10장이 넘는 긴 문서는요?**
스킬이 알아서 병합·요약해 10장 안으로 줄입니다. 뺀 내용은 마지막 슬라이드의 "원문에서 확인" 안내로 대신합니다. 줄이는 게 싫다면 문서를 두 개로 나눠 덱 두 개를 만드세요.

**Q. 회사 로고를 넣고 싶어요.**
현재는 넣지 않는 것이 규칙입니다(파일 자기완결 원칙 + 상표 관리). 필요하면 `DESIGN.md`의 가드레일을 먼저 수정한 뒤 진행하세요.

**Q. 파워포인트(pptx)로 변환할 수 있나요?**
이 스킬의 산출물은 HTML입니다. 발표 자체는 브라우저 전체화면(F11)으로 충분합니다. pptx가 꼭 필요하면 AI에게 별도로 요청하세요.

**Q. 인쇄하거나 PDF로 저장하려면?**
브라우저에서 열고 인쇄(Ctrl+P) → "PDF로 저장"을 쓰면 됩니다. 슬라이드를 한 장씩 넘기며 저장하는 것이 가장 깔끔합니다.
