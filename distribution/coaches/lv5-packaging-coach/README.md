# 통합 Lv.5(에이전트) 코치 (lv5-packaging-coach)

세션 6 · 팀 통합·패키징 및 동작 테스트 · 40~50분

## 무엇을 하나
팀원이 각자 만든 Lv.6 스킬을 **하나의 팀 Lv.5 에이전트로 묶습니다.** 이미 파일에 있는 것은 확인표로 통째로 확인받고, 없는 것만 물어봅니다.

## 입력 (한 폴더에 모아두십시오)
- `SKILL.md` 또는 `skill.md` — 팀원 수만큼 (하위 폴더 포함)
- `*_와이어프레임.md` — 앞 코치가 만든 WFDATA 블록 포함 파일
- `result_reference.html` (같은 폴더)

## 출력
```
{팀이름}-agent/
├─ README.md          폴더를 여는 사람이 먼저 읽는 것
├─ agent-plan.md      인터뷰 결과 · 기획서 (원본 · SSOT)
├─ AGENTS.md          역할 · 입출력 · 도구 · 트리거
├─ CONTRACT.md        스킬 간 입출력 계약
├─ skills/            depth · breadth · coil
└─ data/              입력 · 산출물 · 참고
```
`templates/` 폴더에 골격이 들어 있습니다. 그대로 복사해 채웁니다.

## 진행 순서
0단계 재료 읽기 → 1단계 확인표 3종 한 번에 확인 → 2단계 없는 것만 질문 → 3단계 산출물 생성 → 동작 테스트

## 설계 원칙 5가지
제거 우선 · SSOT · 재작성(re0) · 경계 명시 · 다관점 검증

## 주의
- 내용이 슬라이드와 다르면 **`agent-plan.md`가 맞습니다.** 그것이 유일한 원본입니다.
- 오늘 나오는 것은 MVP입니다. 돌아가는 첫 버전이 목표입니다.
