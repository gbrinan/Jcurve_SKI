# HR Activity Coach 단일 스킬 예시

## TL;DR

`skill/SKILL.md` 한 파일만 `gpt-5.6-luna`에 전달해 가상 제조업 초과근무 감사 업무를 구조화하고, 결과 문서와 자체완결 9면 HTML을 생성한 포터빌리티 예시다.

## 실행 조건

- 모델에 `skill/SKILL.md`와 비식별 업무 요청만 제공한다.
- 기존 Jcurve 예시, 템플릿, 검사기, 과거 출력은 보여 주지 않는다.
- 결과는 `result.md`와 `presentation.html` 두 파일이다.

## 결과

- `output/result.md`: 모더레이터 판정, Mermaid 흐름, Activity 역할, 합성 행과 집계, 사람 인수
- `output/presentation.html`: 로컬에서 바로 열리는 9면 반응형 덱
- `COMPARISON.md`: 1차 실패, 스킬 보강, 2차 결과와 전체 패키지 비교

2차 결과는 375×667, 768×720, 1280×720의 27면 레이아웃 검사를 통과했다. 독립 시각 리뷰에서 발견한 어두운 화면의 흰 패널 대비, 모바일 표 충돌, 흐름 범례 정합을 교정한 뒤 CJK·디자인 무결성 검토도 통과했다.

## 사용 범위

단일 스킬은 워크숍, 초기 설계, 사람 책임 경계 토론, 발표 프로토타입에 적합하다. 실제 CSV 실행기, Jcurve L0–L4, 승인 상태 영속화, 개인정보 런타임 차단을 포함하는 운영 패키지를 대체하지 않는다.

운영에서는 `SKILL.md + schema + runner + QA` 최소 묶음을 권장한다.
