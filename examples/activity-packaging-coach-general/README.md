# 스킬 통합 코치 일반화 예시

스킬 통합 코치는 팀원이 만든 여러 스킬을 읽고 연결해, 필요한 스킬을 골라 쓰는 **스킬팩** 또는 여러 스킬이 순서대로 함께 움직이는 **팀 에이전트**로 만들어 준다.

## TL;DR

단일 `skills/activity-packaging-coach/SKILL.md`와 비식별 가상 구매 입력만으로 실행 가능한 **팀 에이전트**, 단계별 **실행 기록**을 보여주는 실행 확인 화면, 9면 발표 HTML을 생성한 독립 실행 예시다. 이전의 인사 업무 전용 실험물 대신 어느 업무에도 적용할 수 있는 이 스킬을 정본으로 사용한다.

## 구성

- `input/`: 승인된 가상 구매 업무 흐름 데이터, 맥락, 세부 업무 스킬 3개
- `results/reference/team-package/`: `MANIFEST.md`에서 생성 에이전트·스킬·실행 명령을 확인하고 `node run.mjs`로 재생성하는 기준 패키지
- `results/reference/agent-mockup.html`: 설치 없이 바로 확인하는 실행 확인 화면, Edge 브라우저 점검 12/12
- `results/reference/agent-plan-deck.html`: 기준 발표자료, Edge 27/27
- `results/luna/`: Luna 5 원본 결과, 독립 Edge 브라우저 점검 18/27
- `COMPARISON.md`: 관찰 차이, 원인, 변경 제안과 반대 관점

두 실행 모두 기초 구성부터 실행 전 점검까지의 5단계 검사와 사람 정지점을 보존했다. Luna 결과는 모바일·태블릿 화면에서 통과했지만 데스크톱 화면은 바깥 여백 때문에 문서 높이가 화면보다 14px 커졌다. 비교의 재현성을 위해 Luna HTML은 수정하지 않았다.

에이전트 설계 코치의 `tobe.html`은 선택한 업무의 전체 작업 흐름을 확인하고 승인하는 화면이다. 팀원 개개인이 만든 스킬을 넣은 뒤, 실행 시작·기록 재생·진행률·갈림길 결과·사람 확인 대기는 스킬 통합 코치가 만든 `agent-mockup.html`에서 직접 테스트한다. `agent-plan-deck.html`은 같은 결과를 팀 발표용으로 설명한다.

실제 업무에서는 `input/`을 복사하지 말고 비식별화한 승인 업무 흐름 데이터와 해당 업무의 세부 스킬로 교체한다. 이 예시는 외부 전송, 구매 승인, 결제 또는 운영 시스템 쓰기를 수행하지 않는다.
