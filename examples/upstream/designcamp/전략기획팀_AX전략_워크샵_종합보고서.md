#### 8.1 텍스트 기반 흐름도 (To-Be)

**[P-C2-1 월간 실적 마감 및 경영보고] To-Be (노드 13개 → As-Is 대비 루프백 1개 제거)**

```
● 시작
→ A-C2-1-1-1 SAP 실적 데이터 자동 추출 [🤖]
→ A-C2-1-1-2 사업부 제출 현황 자동 확인·독촉 [🤖]
→ A-C2-1-1-3 데이터 정합성 자동 검증 [🤖]
→ A-C2-1-2-1 사업부별 편차율 자동 산출 [🤖]
→ A-C2-1-2-2 편차 임계 초과 항목 자동 식별 [🤖]
◆ 임계 초과 있음?
  Yes → A-C2-1-3-1 소명 요청 자동 발송 [🤖]
      → A-C2-1-3-2 소명 내용 검토 [HITL]
         ↩ A-C2-1-2-1로 루프백
  No  → A-C2-1-4-1 실적 요약·차트 자동 생성 [🤖]
→ A-C2-1-4-2 이슈·시사점 초안 AI 작성 [🤖+HITL]
→ A-C2-1-5-1 보고자료 최종 검토 [HITL]
→ A-C2-1-5-2 경영회의 상정 [HITL]
■ 종료
```

> 수신 확인 루프백(L1)은 자동 독촉으로 제거했다.
> **소명 루프백(L3)은 남긴다** — 소명 검토는 사람의 판단이고, 소명 반영 후 편차 재산출이 반드시 필요하다.

### 9. As-Is vs To-Be 비교

| 항목 | As-Is | To-Be | 개선 |
|---|---|---|---|
| 월 마감 소요 | D+5 | D+2 | ▼3일 |
| 편차 분석 1회차 | 6시간 | 20분 | ▼94.4% |
| 소명 루프백 평균 회차 | 2.4회 | 1.3회 | ▼46% |
| 월 투입 시간 | 234h | 138h | ▼41.0% |

**핵심 발견**: 월 마감 지연의 원인은 **소명 루프백**이다.
편차율을 손으로 산출하니 한 바퀴에 6시간이 걸리고, 소명이 오면 처음부터 다시 돌렸다.
산출을 자동화하면 루프는 남지만 **한 바퀴가 20분으로 줄어** 마감이 3일 앞당겨진다.

### 10. 변화 관리 권고

### 🔴 높은 영향도 역할 — 실적관리담당

- 편차율 산출·재산출이 사라진다. 대신 **소명 내용의 타당성을 판단하는 일**이 남는다.
- 편차 임계값(사업부별로 다르게 적용해 온 기준)을 **하나로 정해야** 자동 판정이 가능하다 (PP-5).
  이것이 AX화의 선행 조건이다.

- BI 대시보드 (Excel→PPT 이관 대체)

#### Activity Coach 인계 사항

- **패키징 단위**: P-C2-1 월간 실적 마감 및 경영보고 (우리 Lv5)

- **루프백**: 소명요청검토 ↩ 편차분석 (탈출: 임계 초과 항목이 0이 되면)
- **사람고유**: 소명요청검토, CEO보고상정
