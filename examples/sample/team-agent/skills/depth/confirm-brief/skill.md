# confirm-brief — 팀장 확인 브리핑

품의초안·재요청초안을 팀장이 모바일에서 1분 안에 판단할 수 있는 확인브리핑으로 압축한다.

- 지난주 초안 대비 변경점만 항목별로 요약한다 (전문을 다시 읽게 하지 않는다 — 인터뷰 발견 1)
- 금액 근거는 견적비교표.xlsx의 해당 행 값을 브리핑 안에 직접 인용한다 (엑셀을 열지 않게)
- 판단 포인트(±15% 변동 건, 검토 필요 건)를 맨 위에 배치한다
- 브리핑 끝에서 팀장 확인을 요청하고 멈춘다. 어떤 것도 자동 발송하지 않는다.
