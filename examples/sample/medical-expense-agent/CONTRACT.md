# 통합 계약 — 의료비 청구 건 판독·지급 판정

Lv4 「의료비 지원 운영」 · Lv5 「의료비 청구 건 판독·지급 판정」의 Lv6 태스크 7개를 이었다.
갈림길이 있어 경로가 3개다.

```contract
tables:
  청구접수대장.csv: 청구번호, 사번, 성명, 진료일, 병원명, 청구금액, 증빙유형, 증빙파일, 진단코드, 수진자관계
  지급기준표.csv: 기준항목, 적용대상, 연간한도, 자기부담률, 필수증빙, 비고
  신청서초안.csv: 청구번호, 사번, 성명, 청구금액, 진단코드, 중증후보, 상태
  지급대장.csv: 청구번호, 사번, 성명, 청구금액, 자기부담률, 지급액, 기준항목, 상태
  예외심사대장.csv: 청구번호, 사번, 성명, 청구금액, 예외사유, 심사근거, 상태
writers:
  신청서초안.csv: 신청서생성
  지급대장.csv: 자동지급상신
  예외심사대장.csv: 예외심사요청
chain: 증빙서류판독 -> 신청서생성 -> 지급기준대조 -> 자동지급상신 -> 지급승인; 증빙서류판독 -> 신청서생성 -> 지급기준대조 -> 보완요청작성; 증빙서류판독 -> 신청서생성 -> 지급기준대조 -> 예외심사요청 -> 지급승인
payloads: 의료비청구건판독·지급판정입력, 증빙서류판독결과, 신청서생성결과, 지급기준대조결과, 자동지급상신결과, 보완요청작성결과, 예외심사요청결과, 지급승인결과
threshold: (해당 없음 — 금액 임계값은 지급기준표.csv의 연간한도가 정한다)
halt_at: 지급승인, 보완요청작성
```
