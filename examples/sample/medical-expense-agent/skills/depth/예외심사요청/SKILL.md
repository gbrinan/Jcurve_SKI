# 예외심사요청

> 상류: 워크플로우 설계도 · Lv6 「예외심사요청」 · Human 여부: 증강 · Skill화 용이성: 낮음

## 판단기준
- 왜 예외인지 사유를 지급기준표.csv의 기준항목 이름으로 적는다.
- 심사자가 판단할 근거(청구금액·한도·수진자관계)를 한 줄로 정리해 붙인다.
- 지급 여부를 추천하지 않는다. 판단은 심사자가 한다.

## 예외
- 사유를 특정할 수 없으면 `사유불명`으로 적고 넘긴다. 그럴듯한 사유를 지어내지 않는다.

## 사람이 확인하고 멈추는 지점
- 예외심사대장.csv에 올리기만 한다. 심사 결과를 대신 정하지 않는다.
