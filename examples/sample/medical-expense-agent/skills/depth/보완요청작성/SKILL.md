# 보완요청작성

> 상류: 워크플로우 설계도 · Lv6 「보완요청작성」 · Human 여부: 증강 · Skill화 용이성: 중간

## 판단기준
- 무엇이 빠졌는지 항목으로 적는다. "서류 미비"처럼 뭉뚱그리지 않는다.
- 재제출 기한을 안내문에 넣는다(접수일 +14일).

## 예외
- 같은 청구번호로 이미 보완요청이 나갔으면 다시 만들지 않는다.

## 사람이 확인하고 멈추는 지점
- 이 갈래의 끝이다. 보완 안내문을 **초안으로만** 만들고, 담당자가 확인할 때까지 멈춘다.
  신청자에게 자동으로 발송하지 않는다.
