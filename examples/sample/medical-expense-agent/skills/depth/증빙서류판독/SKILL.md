# 증빙서류판독

> 상류: 워크플로우 설계도 · Lv4 「의료비 지원 운영」 · Lv5 「의료비 청구 건 판독·지급 판정」 · Lv6 「증빙서류판독」
> Human 여부: 자동 · Skill화 용이성: 높음
> AX 과제: Talent AX실 「의료비 판독 AI」 — "OCR 기반 의료비 증빙서류에서 Data 추출"

## 판단기준
- 청구접수대장.csv의 각 행에서 증빙유형·증빙파일·진단코드·청구금액을 읽는다.
- 증빙유형에 「영수증」이 없으면 **판독 불가**로 표시한다. 금액을 추정하지 않는다.
- 진단코드 첫 글자가 `C`면 중증질환 후보로 표시한다. 확정은 다음 단계가 한다.

## 예외
- 증빙파일 칸이 비어 있으면 판독 불가. OCR을 시도하지 않는다.
- 청구금액이 0 이하이면 판독 불가로 넘긴다.
