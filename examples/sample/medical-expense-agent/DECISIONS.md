# 이 팩을 어떻게 읽었는가 (readchk)

> 작업을 시작하기 전에 남기는 기록입니다. 나중에 읽는 사람이 "이 팩이 의도대로 만들어졌는지"를 이 문서와 대조해 확인할 수 있습니다.

## 이해한 바

- 출처 업무: Lv4 「의료비 지원 운영」 › Lv5 「의료비 청구 건 판독·지급 판정」
- 스킬 7개를 갈림길·루프백이 있는 흐름으로 이었다: 증빙서류판독 → 신청서생성 → 지급기준대조 → 자동지급상신 → 지급승인
- AI가 맡는 태스크 6개, 사람이 직접 하는 태스크 1개 (지급승인)
- 산출물 유형: 팀 에이전트(갈림길 있음)
- 흐름의 끝: 보완요청작성, 지급승인

## 아직 정해지지 않은 것

정해지지 않은 것이 없습니다. 모든 항목이 파일에서 확정되었습니다.

이 미결이 남아 있어도 팩은 그대로 돌아갑니다. 결정이 나면 해당 파일을 고치고 이 문서를 갱신하십시오.
