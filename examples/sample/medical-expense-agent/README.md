## 왜 스킬팩이 아니라 에이전트인가

과제 상세에 적힌 한 문장이 갈림길입니다 — *"운영 기준에 따라 **지급 여부 판단**"*.
판정 결과에 따라 뒤에 오는 일이 통째로 달라집니다.

```
증빙서류판독[자동] → 신청서생성[자동] → 지급기준대조[증강] ◆
                                          ├─ 기준 충족    → 자동지급상신[자동] ─┐
                                          ├─ 증빙 미비    → 보완요청작성[증강] → 끝
                                          └─ 모호·한도초과 → 예외심사요청[증강] ─┤
                                                                    지급승인[사람고유] ⛔
```

## 돌려보기

```bash
python3 examples/sample/medical-expense-agent/run.py
```

청구 11건이 갈림길에서 **세 갈래로 갈라져** 서로 다른 파일로 떨어집니다.

| 경로 | 건수 | 산출물 |
|---|---|---|
| A 자동지급 | 6건 | `out/지급대장.csv` (전부 상태 `승인대기`) |
| B 보완요청 | 1건 | `out/보완요청안내문.md` (발송 안 함) |
| C 예외심사 | 4건 | `out/예외심사대장.csv` (지급 여부 추천 없음) |
| 합류 | — | `out/승인대기목록.md` — 여기서 **멈춤** |

경로 C의 4건은 예외 사유가 저마다 다릅니다 — 자기부담률 100%, 연간한도 초과,
적용대상 아닌 수진자관계, 기준항목 특정 불가. 네 가지 분기 조건이 실제로 각각 걸립니다.

## 사람이 멈추는 자리

- **지급승인** — 사람고유. 팀장이 승인할 때까지 멈춥니다. **지급 실행 코드가 이 팩에 없습니다.**
- **보완요청작성** — 안내문 초안까지만. 신청자에게 자동으로 보내지 않습니다.
