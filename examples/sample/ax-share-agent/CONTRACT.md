# 통합 계약 — 계열사 AX전략 팀장에게 공유

Lv4 「AX전략 공유하기」 · Lv5 「계열사 AX전략 팀장에게 공유」의 Lv6 태스크 4개를 하나로 이었다.

```contract
tables:
  공유대상자후보.csv: 이름, 소속, 직책, 대상여부
  회의록목록.csv: 파일명, 주제, 일자
  공유대상자목록.csv: 이름, 소속, 직책
  첨부파일목록.md: 파일명, 일자

writers:
  공유대상자목록.csv: 공유대상자목록정리
  첨부파일목록.md: 관련회의록첨부

chain: 공유대상자목록정리 -> 관련회의록첨부 -> 메일본문작성 -> 메일발송

payloads: 공유대상자후보, 회의록후보, 공유대상자목록결과, 첨부파일목록결과, 메일초안, 발송대기

threshold: (해당 없음 — 이 팩은 임계값 기반 정지가 없다)
halt_at: 메일발송
```
