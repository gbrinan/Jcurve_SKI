# 잔액브리핑초안기

## 1. 언제 쓰는가 (시작 조건)
이상잔액플래거가 이상후보목록.csv를 만든 직후.

## 2. 무엇이 필요한가 (입력)
`이상후보목록.csv`.

## 3. 어떤 순서로 (절차)
1. 이상 후보를 사유별로 묶는다
2. 표와 요약 3줄로 검토 브리핑을 만든다
3. 팀장 앞 메일 초안을 만든다 — **발송하지 않는다**

## 4. 무엇을 기준으로 판단하나 (판단 기준)
- 만약 이상 후보가 0건이면 "이상 없음"으로 한 줄만 남긴다
- 만약 부호 반전 건이 있으면 목록 맨 위에 올린다

## 5. 무엇을 내놓나 (산출물)
`검토브리핑.md` — 판단 포인트 · 사유별 표 · 요약 3줄
`메일초안.md` — 팀장 앞 초안 (발송하지 않음)

## 6. 언제 끝난 건가 (완료 조건)
두 파일이 out/에 생성되었을 때. **에이전트는 여기서 멈추고 결산담당의 확인을 요청한다.**
확인 전에는 어떤 것도 다음 단계로 진행하지 않는다.

## 7. 하지 말 것 (제약 조건)
- 메일을 발송하지 않는다. 초안까지가 끝이다
- 이상 후보를 임의로 제외하지 않는다
