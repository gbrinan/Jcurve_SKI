# 이상잔액플래거

## 1. 언제 쓰는가 (시작 조건)
잔액표준화기가 표준잔액표.csv를 만든 직후.

## 2. 무엇이 필요한가 (입력)
`표준잔액표.csv` — 계정별 당기·전기 잔액.

## 3. 어떤 순서로 (절차)
1. 계정별 증감률 (당기-전기)/전기 를 계산한다
2. 임계값을 넘거나 부호가 반전된 계정을 이상 후보로 표시한다
3. 이상 후보 목록을 만든다

## 4. 무엇을 기준으로 판단하나 (판단 기준)
- 만약 증감률이 ±10%를 초과하면 이상 후보로 표시한다
- 만약 전기와 당기의 부호가 반전되면 증감률과 무관하게 이상 후보로 표시한다
- 만약 전기 값이 0이면 증감률 대신 "신규"로 표기하고 이상 후보에 넣는다
- 판정이 애매하면(경계값 ±10%) 후보에 넣고 사람 확인으로 넘긴다

## 5. 무엇을 내놓나 (산출물)
`이상후보목록.csv` — 계정코드·계정명·전기·당기·증감률·사유

## 6. 언제 끝난 건가 (완료 조건)
이상후보목록.csv가 생성되고 사유가 모든 행에 채워졌을 때.

## 7. 하지 말 것 (제약 조건)
- 이상 여부를 확정하지 않는다. 확정은 사람이 한다
- 임계값을 임의로 바꾸지 않는다 (CONTRACT.md의 threshold를 따른다)
