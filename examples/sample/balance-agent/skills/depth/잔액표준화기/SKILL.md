# 잔액표준화기

## 1. 언제 쓰는가 (시작 조건)
분기 결산 착수일, 공유폴더에 원장잔액과 계열사잔액 파일이 모였을 때.

## 2. 무엇이 필요한가 (입력)
`원장잔액_{분기}.csv` 1개와 `계열사잔액_*.csv` N개. 열은 계정코드·계정명·당기잔액·전기잔액.

## 3. 어떤 순서로 (절차)
1. 공유폴더에서 원장·계열사 파일을 모두 읽는다
2. 계정코드를 기준으로 원장과 계열사 잔액을 한 표로 병합한다
3. 원장에 없는 계정코드는 미매칭 목록으로 분리한다

## 4. 무엇을 기준으로 판단하나 (판단 기준)
- 만약 계열사 계정코드가 원장에 있으면 해당 행에 합산한다
- 만약 원장에 없는 계정코드면 미매칭 목록으로 분리하고 표에 넣지 않는다

## 5. 무엇을 내놓나 (산출물)
`표준잔액표.csv` — 계정코드·계정명·당기잔액·전기잔액·출처수
`미매칭목록.md` — 원장에 없는 계정코드와 그 출처 파일

## 6. 언제 끝난 건가 (완료 조건)
표준잔액표.csv가 생성되고, 읽은 파일 수와 병합 건수가 로그에 남았을 때.

## 7. 하지 말 것 (제약 조건)
- 원본 CSV를 수정하지 않는다
- 미매칭 계정을 임의로 매핑하지 않는다
