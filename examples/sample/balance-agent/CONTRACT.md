# 재무1조 통합 계약 (CONTRACT)

와이어프레임(계정별 잔액 확인)에서 확정한 이름을 정본으로 발급한 계약이다.
개인은 SKILL.md 본문을 자유롭게 쓰되, 아래 이름은 문자열 그대로 지킨다.

```contract
tables:
  원장잔액_2026Q2.csv: 계정코드, 계정명, 당기잔액, 전기잔액
  계열사잔액_SK온.csv: 계정코드, 계정명, 당기잔액, 전기잔액
  계열사잔액_SK엔무브.csv: 계정코드, 계정명, 당기잔액, 전기잔액
  표준잔액표.csv: 계정코드, 계정명, 당기잔액, 전기잔액, 출처수
  이상후보목록.csv: 계정코드, 계정명, 전기, 당기, 증감률, 사유
writers:
  표준잔액표.csv: 잔액표준화기
  이상후보목록.csv: 이상잔액플래거
chain: 잔액표준화기 -> 이상잔액플래거 -> 잔액브리핑초안기
payloads: 잔액원본, 표준잔액표, 이상후보목록, 검토브리핑
threshold: ±10%
halt_at: 잔액브리핑초안기
```

## 계약이 정하지 않는 것
- 스킬 본문의 서술 방식, 예외 메시지 문구
- 브리핑의 문장 표현

## 위반 시 처리
`check_contract.py`가 제출된 스킬을 계약과 대조해 🟢/🟡/🔴 로 분기한다.
