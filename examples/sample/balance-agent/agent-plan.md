# 재무1조 팀 에이전트 기획서

## 1. 팀과 목적
- 재무본부 회계관리팀 재무1조 (결산담당 2~3명). 분기 결산의 계정별 잔액 확인에 회차당 약 10시간 소모.
- 에이전트 목적: 잔액 취합 → 이상 후보 선별 → 검토 브리핑 초안까지 자동화.

## 2. 에이전트 역할 정의
- 한 문장: "원장·계열사 잔액을 한 표로 맞추고 이상 후보를 골라 검토 브리핑 초안을 만든다."
- 하는 일: 잔액 병합, 증감률 계산, 이상 후보 표시, 브리핑·메일 초안 작성
- 하지 않는 일: 이상 여부 확정, 메일 발송, 원장 수정

## 4. 대표 시나리오
- 트리거: 분기 결산 착수일, 결산담당이 공유폴더를 지정
- 입력: 잔액원본(원장 1 + 계열사 N)
- 처리: 계정코드 병합 → 증감률 계산 → ±10%·부호반전 판정
- 출력: 검토브리핑 + 메일초안 (발송하지 않음)
- 파이프라인: 잔액표준화기 → 이상잔액플래거 → 잔액브리핑초안기

## 5. 결과물 반영 규칙
- 병합 결과는 표준잔액표.csv에 기록
- 원장에 없는 계정코드는 기록하지 않고 미매칭목록.md로 분리
- 이상 후보는 이상후보목록.csv에 사유와 함께 기록

## 6. 연동 맵
- 현재는 독립. 🚧 SAP 원장 직접 연동은 권한 미개통 — 사람이 엑셀을 추출해 공유폴더에 둔다.

## 7. 검증·휴먼인더루프 지점
- 잔액브리핑초안기에서 정지, 결산담당이 이상 후보의 원인을 확인하고 확정/해제
- 증감률 ±10% 초과 또는 부호 반전 시 이상 후보로 올리되 에이전트가 확정하지 않음
- 발송·공유는 사람만 한다
