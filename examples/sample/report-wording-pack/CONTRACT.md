# 통합 계약 (워크플로우 설계도 변환 초안)

Lv4 「전사 경영전략실 송부 정기보고서 작성(본부장 Monthly, CEO Weekly 등)」 · Lv5 「정확하고 간결한 내용 정리」의 Lv6 태스크 3개를 순서대로 이었다.

```contract
tables:
  (미정): (설계도 단계엔 표·칸 명세가 없음)
writers:
  (미정): (미정)
chain: 내용의맥락파악 -> 보고사항으로적절한지에대한판단 -> 워딩
payloads: 정확하고간결한내용정리입력, 내용의맥락파악결과, 보고사항으로적절한지에대한판단결과, 워딩결과
threshold: (해당 없음)
halt_at: 보고사항으로적절한지에대한판단
```
