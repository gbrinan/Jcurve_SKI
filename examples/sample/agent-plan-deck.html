구매기획팀
Lv.5 에이전트

견적 취합 → 비교표 갱신 → 발주 품의 초안 자동화

팀장 1 + 팀원 2 주 6시간 절감 목표
1 · 팀과 목적

주간 견적 비교·품의 준비에 매주 6시간을 쓴다

  • 반복 업무: 견적 메일 취합 → 비교표 작성 → 품의 초안
  • 에이전트가 취합·작성을 맡고, 사람은 판단·승인만
2 · 역할 정의

"견적 메일을 읽어 비교표를 갱신하고 품의 초안을 만든다"

  • 하는 일: 견적 파싱 · 비교표 기록 · 품의 초안 작성
  • 하지 않는 일: 발주 승인 · 공급사와의 직접 소통
3 · 데이터 명세

원본은 공용드라이브 data 폴더 한 곳

표주요 칸읽기/쓰기
견적비교표.xlsx공급사 · 품목 · 단가 · 납기 · 수신일쓰기
승인공급사목록.xlsx공급사 · 등급 · 담당자읽기

SSOT: 공용드라이브/구매기획/data — 다른 위치에 사본을 만들지 않는다

4 · 대표 시나리오

월요일 09:00, 폴더 지정 한 번이면 끝

  • 트리거: 팀원이 지난주 견적 메일 폴더 지정
  • 입력: 견적 메일(PDF 첨부 포함)
  • 처리: 파싱 → 승인공급사 대조 → 미승인 건 분리
  • 출력: 비교표 갱신 + 품의 초안(md)
5 · 반영과 검증

돈이 걸린 문서는 사람이 마지막에 선다

  • 결과는 견적비교표의 해당 품목 행에 기록, 미승인 공급사는 "검토 필요"로 분리
  • 휴먼인더루프: 품의 초안 발송 전 팀장 확인 필수
  • 단가 ±15% 이상 변동 시 에이전트가 멈추고 확인 요청
  • 연동: 현재 독립 · 차기 결재 시스템 스킬로 초안 전달
