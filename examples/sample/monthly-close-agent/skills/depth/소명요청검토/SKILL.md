# 소명요청검토

> 상류: 워크플로우 설계도 · Lv4 「실적관리」 · Lv5 「월간 실적 마감 및 경영보고」 · Lv6 「소명요청검토」
> Human 여부: 사람고유 · Skill화 용이성: 낮음

## 갈림길
이 태스크의 결과에 따라 다음이 갈린다: 편차분석(루프백).
판단기준(원본 흐름도의 ◆): 소명을 반영해 편차를 다시 산출한다. 임계 초과 항목이 0이 되면 반복이 끝난다

## 되돌아가기 (루프백)
- 이 태스크에서 편차분석(으)로 되돌아간다 — 소명이 반영되면 편차 판정이 달라진다.
- 반복이 끝나는 조건: 임계초과가 0이 되면 끝난다.
- 5회차까지 초과가 남으면 반복을 멈추고 사람에게 넘긴다 — 무한히 돌지 않는다.
  소명이 없거나 인정되지 않은 항목은 스킬이 해소할 수 없다.

## 판단기준
- 임계를 넘은 항목의 **소명 요청 목록과 근거(편차율·임계율)만** 만든다.
- **소명을 인정할지 정하지 않는다.** 인정 판단은 기획담당의 몫이다.
- 소명이 아직 오지 않은 항목은 `소명 미회신`으로 표시한다 — 사유를 지어내지 않는다.

## 사람이 확인하고 멈추는 지점
- 소명요청검토 — 사람이 직접 판단한다. 자동으로 진행하지 않는다.
- 인정이 확정되었다고 사람이 알려주기 전에는 되돌아가지 않는다.

## 관련 Pain Point
- **PP-4 [COMM/높음]** 소명 요청·회신 메일 왕복 — 요청 목록을 한 번에 만들어 왕복을 줄인다.
  다만 **메일을 대신 보내지 않는다.**
