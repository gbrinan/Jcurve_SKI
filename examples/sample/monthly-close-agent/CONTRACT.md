# 통합 계약 (워크플로우 설계도 변환 초안)

Lv4 「실적관리」 · Lv5 「월간 실적 마감 및 경영보고」의 Lv6 태스크 5개를 이었다. 갈림길이 있어 경로가 2개다.
루프백: 소명요청검토 ↩ 편차분석 (탈출: 소명을 반영해 편차를 다시 산출한다. 임계 초과 항목이 0이 되면 반복이 끝난다)

```contract
tables:
  (미정): (설계도 단계엔 표·칸 명세가 없음)
writers:
  (미정): (미정)
chain: 사업부실적취합 -> 편차분석 -> 소명요청검토; 사업부실적취합 -> 편차분석 -> 경영보고서작성 -> CEO보고상정
payloads: 월간실적마감및경영보고입력, 사업부실적취합결과, 편차분석결과, 소명요청검토결과, 경영보고서작성결과, CEO보고상정결과
threshold: (해당 없음)
halt_at: 소명요청검토, CEO보고상정
```
