# 월간 실적 마감 및 경영보고 — 팀 에이전트 (갈림길 + 루프백)

**전략기획 사례**입니다. 원본 워크샵이 **PP 집중 구간(노드 16개)**으로 지목한 프로세스입니다.

- 출처: **AX전략 워크샵 · 전략기획팀** — 워크플로우 설계도에서 옮겼습니다.
- 원본 프로세스: **P-C2-1 월간 실적 마감 및 경영보고** (🔴PP집중)
- 산출물 유형: **팀 에이전트 (갈림길·루프백 있음)** — AI 태스크 3개(ATF③) · 갈림길 1곳 + 루프백 1곳(ATF④)

## 흐름

```
사업부실적취합[자동] → 편차분석[자동] ◆ 임계 초과 있음?
                          ↑            │
      ↩ 소명 반영 후 재산출 │            ├─ Yes → 소명요청검토[사람고유]
      (임계초과 0이면 탈출) └────────────┘
                                        └─ No  → 경영보고서작성[증강] → CEO보고상정[사람고유] ⛔
```

```
    · 석유사업 영업이익 — 편차율 -22.8% (임계 15%) · 소명 접수됨
    · 배터리사업 매출 — 편차율 -25.3% (임계 10%) · 소명 접수됨
[소명요청검토] ↩ 편차분석으로 되돌아감 (탈출 조건: 임계초과 0)
[편차분석] [2회차] 항목 8건 · 임계초과 0건 · 소명인정 2건 (초과에서 뺌)
◆ 임계 초과 있음? → No · 경영보고서작성으로 진행 (2회차에 탈출)
[경영보고서작성] 절 5개 중 작성 4개 · 자료없음 1개 (전망을 지어내지 않음)
[CEO보고상정] ⛔ 사람고유 — 점검표 5건만 만들고 멈춤
```

## 원본 Pain Point를 어디서 다루는가

| Pain Point | 이 팩의 대응 |
|---|---|
| **PP-1 [WAIT]** 사업부 실적 수신 지연 | 미제출을 0으로 채우지 않고 표시 · 수신을 앞당기지는 못함 |
| **PP-3 [RPT]** 편차율 매월 수기 산출 | `편차분석`이 자동 산출 |
| **PP-5 [DEC]** 임계 기준이 사업부마다 다름 | `편차임계` 표 **하나로 통일** — 기준이 하나면 판단이 흔들리지 않음 |
| **PP-4 [COMM]** 소명 요청·회신 메일 왕복 | 요청 목록을 한 번에 생성 · **메일을 대신 보내지 않음** |
| **PP-2 [MAN]** SAP→Excel→PPT 수동 이관 | `경영보고서작성`이 절별 초안 · 서식 확정은 사람 |

## 지어내지 않는 것이 실행에서 보입니다

| 상황 | 에이전트가 한 일 |
|---|---|
| 사업부 1곳 미제출 (시스템 장애) | 실적을 0으로 채우지 않고 **편차 분석에서 제외** |
| 마감 후 제출 1곳 | 제출은 제출로 세되 `지각제출`로 구분 |
| 계획이 음수인 항목 (배터리 영업이익) | 절대값으로 나눠 편차율 계산 · 부호에 속지 않음 |
| 소명이 없는 초과 | 소명을 지어내지 않고 `소명 미회신`으로 표시 |
| 보고서 선택 절 (익월 전망) | 근거 데이터가 없어 `자료없음` — **전망을 만들지 않음** |
| 소명이 끝내 인정되지 않으면 | 5회차에서 멈추고 사람에게 넘김 — 무한히 돌지 않음 |

## 실행 화면

`agent-mockup.html`을 브라우저로 엽니다. **▶ 실행**을 누르면 ● 시작부터 한 단계씩 돕니다.
1회차에서 갈라져 되돌아왔다가 2회차에 빠져나가는 장면이 재생되고,
**소명요청검토에서 멈춥니다.**

## 사람이 멈추는 자리

- **소명요청검토** — 기획담당이 소명 인정을 판단할 때까지 멈춥니다.
  **소명을 인정할지 대신 정하지 않고, 메일도 대신 보내지 않습니다.**
- **CEO보고상정** — 전략기획팀장이 점검표를 확인할 때까지 멈춥니다.
  **보고서 확정·상정 코드가 이 팩에 없습니다.**

## 데이터

`data/실적데이터.md` **한 파일**에 표 5개가 들어 있습니다. 전부 **실습용 가상 값**입니다.

| 고칠 것 | 일어나는 일 |
|---|---|
| 편차임계 임계율을 `30%`로 | 초과가 0이 되어 **루프백 없이 바로 경영보고서작성** |
| 소명접수 `BU-04` 줄의 `인정` → `미인정` | 초과가 남아 **5회차까지 돌다 멈춤** |
| 소명접수 `BU-01` 줄 삭제 | 소명 없는 초과가 남아 같은 결과 |
| `BU-05`를 제출로 바꾸고 실적을 채우면 | 편차 분석 대상이 4곳 → 5곳 |
