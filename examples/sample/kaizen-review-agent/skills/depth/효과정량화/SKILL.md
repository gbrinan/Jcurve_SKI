# 효과정량화

> 상류: 워크플로우 설계도 · Lv4 「개선과제」 · Lv5 「개선과제 발굴 및 심의」 · Lv6 「효과정량화」
> Human 여부: 자동 · Skill화 용이성: 높음

## 판단기준
- 연간 절감액 = 절감시간 × 대상인원 × `산정기준`의 시간당인건비.
- 근거출처가 비어 있으면 금액은 계산하되 `근거없음`으로 표시한다 —
  **근거를 지어내지 않는다.**
- `효과산정` 표에 아예 없는 과제는 금액을 만들지 않고 `효과미산정`으로 남긴다.

## 예외
- 조정이 확정되어 되돌아온 경우(루프백), 제안자가 보완한 근거를 반영해 다시 산정한다.
  보완 내용은 사람이 제출한 것만 쓴다.
