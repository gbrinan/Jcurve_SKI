# 심의상정

> 상류: 워크플로우 설계도 · Lv4 「개선과제」 · Lv5 「개선과제 발굴 및 심의」 · Lv6 「심의상정」
> Human 여부: 증강 · Skill화 용이성: 중간

## 판단기준
- C 등급 과제를 `심의일정` 표의 회차로 묶어 안건 목록을 만든다.
- 심의 회차 정보가 없으면 `회차미정`으로 남긴다 — 일정을 지어내지 않는다.
- **일정을 앞당기지 않는다.** 상정마감일이 지난 과제는 다음 회차로 넘긴다.

## ⛔ 이 스킬이 하지 않는 것
- **심의를 대신하지 않는다.** 안건 목록까지다.
- 안건의 우선순위나 채택 여부를 정하지 않는다.
