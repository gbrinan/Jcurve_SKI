# 적합성심사

> 상류: 워크플로우 설계도 · Lv4 「개선과제」 · Lv5 「개선과제 발굴 및 심의」 · Lv6 「적합성심사」
> Human 여부: 증강 · Skill화 용이성: 중간

## 갈림길
이 태스크의 결과에 따라 다음이 갈린다: 즉시실행통보 또는 보완요청 또는 심의상정.

판단기준(원본 흐름도의 ◆): 심사 등급? A(즉시실행) -> 즉시실행통보; B(보완필요) -> 보완요청; C(심의필요) -> 심의상정

- **판정 순서는 B → C → A**다. 순서를 바꾸면 결과가 달라진다.
- B: 근거가 없거나 효과 산정이 불가한 과제. **금액이 아무리 커도 먼저 보완을 요구한다** —
  근거 없는 큰 숫자를 심의에 올리지 않는다.
- C: 연간 절감액이 `산정기준`의 심의필요하한 이상인 과제.
- A: 투자비가 즉시실행상한 이하이고 근거가 있는 과제.
- 세 조건 중 어디에도 걸리지 않으면 C(심의상정)로 보낸다 — 애매하면 사람이 보게 한다.

## 판단기준
- 기준값은 `산정기준` 표 **하나뿐**이다. 심사자마다 다른 기준을 쓰지 않는다.
- 등급을 사람이 바꾸라고 하기 전에는 스스로 바꾸지 않는다.
