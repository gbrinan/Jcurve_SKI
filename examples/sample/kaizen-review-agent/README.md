# 개선과제 발굴 및 심의 — 팀 에이전트 (3갈래 갈림길 + 루프백)

**운영효율화 사례**입니다. 지금까지 팩 중 **갈림길이 가장 복잡**합니다 — 2갈래가 아니라 3갈래입니다.

- 출처: **AX전략 워크샵 · 운영혁신팀** — 워크플로우 설계도에서 옮겼습니다.
- 원본 프로세스: **P-D1-1 개선과제 발굴 및 심의**
- 산출물 유형: **팀 에이전트 (갈림길·루프백 있음)** — AI 태스크 4개(ATF③) · 갈림길 1곳(3갈래) + 루프백 1곳(ATF④)

## 흐름

```
아이디어접수[자동] → 효과정량화[자동] → 적합성심사[증강] ◆ 심사 등급?
                        ↑                     │
   ↩ 보완 후 재산정      │                     ├─ A → 즉시실행통보[사람고유] ⛔
   (B 0건이면 탈출)      └─── B ───────────────┤
                                              └─ C → 심의상정[증강] → 심의결과통보[사람고유] ⛔
```

## 판정 순서가 곧 안전장치입니다

심사 순서는 **B → C → A**입니다. 순서를 바꾸면 결과가 달라집니다.

| 순서 | 조건 | 등급 | 다음 |
|---|---|---|---|
| 1 | 근거출처가 없거나 효과 산정 불가 | **B** | 보완요청 (루프백) |
| 2 | 연간 절감액 ≥ 5,000만원 | **C** | 심의상정 |
| 3 | 투자비 ≤ 500만원 이고 근거 있음 | **A** | 즉시실행통보 |
| — | 어디에도 안 걸리면 | **C** | 심의상정 (애매하면 사람이 본다) |

근거가 없으면 **금액이 아무리 커도 먼저 보완을 요구합니다** —
근거 없는 큰 숫자를 심의에 올리지 않습니다.

```
◆ 심사 등급? → B 없음 · A 2건은 즉시실행통보, C 5건은 심의상정으로 진행 (2회차에 탈출)
[즉시실행통보] ⛔ 사람고유 — 즉시실행 대상 2건의 목록만 만들고 멈춤 (통보하지 않음)
[심의상정] 심의 안건 5건 · 2026-3Q-2 (개최 2026-09-25 · 상정마감 2026-09-18)
[심의결과통보] ⛔ 사람고유 — 점검표 9건만 만들고 멈춤 (심의 미개최 — 결과를 지어내지 않음)
```

## 이 팩에서 가장 중요한 한 가지

**심의결과통보는 흐름의 끝이지만 결과를 만들지 않습니다.**
심의위원회가 열려야 결과가 생기기 때문입니다. 회의 전이면 결과 칸을 비워 두고
**"심의 미개최 — 결과가 없으므로 통보문을 만들지 않음"** 이라고 적습니다.
없는 결과를 지어내지 않는다는 원칙이 가장 선명하게 드러나는 자리입니다.

## 지어내지 않는 것이 실행에서 보입니다

| 상황 | 에이전트가 한 일 |
|---|---|
| 반려된 제안 1건 | 집계에서 빼되 **표에서 지우지 않고** 점검표에 남김 |
| 근거출처가 빈 제안 (K-04) | 금액은 계산하되 `근거없음` · **B로 보내 보완 요구** |
| 효과 자료 자체가 없는 과제 | 금액을 만들지 않고 `효과미산정` |
| 심의 회차가 미정이면 | `회차미정`으로 남김 — 일정을 지어내지 않음 |
| 심의가 아직 안 열림 | **결과 칸을 비워 두고 통보문을 만들지 않음** |
| 보완이 끝내 안 되면 | 5회차에서 멈추고 사람에게 넘김 — 무한히 돌지 않음 |

## 사람이 멈추는 자리 (3곳)

- **보완요청** — 제안자가 근거를 보완할 때까지 멈춥니다. **근거를 대신 만들지 않습니다.**
- **즉시실행통보** — 팀장 전결 대상 목록만 만들고 멈춥니다. **통보·실행 지시를 하지 않습니다.**
- **심의결과통보** — **심의 결과를 만들지 않고** 멈춥니다.
