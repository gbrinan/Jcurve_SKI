# 통합 계약 (워크플로우 설계도 변환 초안)

Lv4 「개선과제」 · Lv5 「개선과제 발굴 및 심의」의 Lv6 태스크 7개를 이었다. 갈림길이 있어 경로가 3개다.
루프백: 보완요청 ↩ 효과정량화 (탈출: 보완된 제안은 효과 정량화부터 다시 돈다. A 또는 C로 판정되면 반복이 끝난다)

```contract
tables:
  (미정): (설계도 단계엔 표·칸 명세가 없음)
writers:
  (미정): (미정)
chain: 아이디어접수 -> 효과정량화 -> 적합성심사 -> 즉시실행통보; 아이디어접수 -> 효과정량화 -> 적합성심사 -> 보완요청; 아이디어접수 -> 효과정량화 -> 적합성심사 -> 심의상정 -> 심의결과통보
payloads: 개선과제발굴및심의입력, 아이디어접수결과, 효과정량화결과, 적합성심사결과, 즉시실행통보결과, 보완요청결과, 심의상정결과, 심의결과통보결과
threshold: (해당 없음)
halt_at: 즉시실행통보, 보완요청, 심의결과통보
```
