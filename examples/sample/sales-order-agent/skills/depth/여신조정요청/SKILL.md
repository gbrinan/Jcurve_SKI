# 여신조정요청

> 상류: 워크플로우 설계도 · Lv4 「석유제품 영업」 · Lv5 「월간 수주·여신 심사」 · Lv6 「여신조정요청」
> Human 여부: 사람고유 · Skill화 용이성: 낮음

## 갈림길
이 태스크의 결과에 따라 다음이 갈린다: 공급가능확인(루프백).
판단기준(원본 흐름도의 ◆): 조정 후 재점검한다. 한도초과가 0이 되면 반복이 끝난다

## 되돌아가기 (루프백)
- 이 태스크에서 공급가능확인(으)로 되돌아간다 — 물량이 줄면 공급도 여신도 다시 계산된다.
- 반복이 끝나는 조건: 한도초과가 0이 되면 끝난다.
- 5회차까지 초과가 남으면 반복을 멈추고 사람에게 넘긴다 — 무한히 돌지 않는다.

## 판단기준
- 한도를 넘은 거래처의 **목록과 근거(한도·합계·초과액·여유액)만** 만든다.
- **어느 주문을 얼마나 줄일지 정하지 않는다.** 조정은 영업담당의 판단이다.
- 여신 한도를 올려주지 않는다. 한도 상향은 여신담당의 권한이다.

## 사람이 확인하고 멈추는 지점
- 여신조정요청 — 사람이 직접 판단한다. 자동으로 진행하지 않는다.
- 조정이 확정되었다고 사람이 알려주기 전에는 되돌아가지 않는다.
