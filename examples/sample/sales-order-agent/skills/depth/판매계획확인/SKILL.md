# 판매계획확인

> 상류: 워크플로우 설계도 · Lv4 「석유제품 영업」 · Lv5 「월간 수주·여신 심사」 · Lv6 「판매계획확인」
> Human 여부: 자동 · Skill화 용이성: 높음

## 판단기준
- `판매계획` 표에서 진척률 = 누계실적 ÷ 월간계획량을 계산한다.
- 진척률이 **80% 미만**이면 `미달`로 표시한다.
- **계획도 주문도 바꾸지 않는다.** 어디가 뒤처졌는지 보이게 만들 뿐이다.

## 예외
- 월간계획량이 0인 제품은 진척률을 계산하지 않고 사람에게 넘긴다 — 0으로 나누지 않는다.
