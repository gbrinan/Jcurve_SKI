# 공급가능확인

> 상류: 워크플로우 설계도 · Lv4 「석유제품 영업」 · Lv5 「월간 수주·여신 심사」 · Lv6 「공급가능확인」
> Human 여부: 증강 · Skill화 용이성: 중간

## 판단기준
- 공급가능량 = `재고생산` 표의 가용재고 + 생산예정이다. 스킬이 더해서 만든다.
- 제품별 주문 합계(접수분만)와 견줘 공급가능량보다 많으면 `부족`으로 표시한다.
- **부족분을 어느 주문에서 뺄지 정하지 않는다.** 배분은 영업담당의 판단이다.
- 주문을 임의로 줄이지 않는다. 부족은 부족대로 표시하고 넘긴다.

## 예외
- 재고생산 표에 없는 제품의 주문은 공급가능량을 0으로 보지 않고 사람에게 넘긴다 —
  재고를 모르는 것과 재고가 없는 것은 다르다.
- 조정이 확정되어 되돌아온 경우(루프백), 확정된 주문량으로 다시 계산한다.
