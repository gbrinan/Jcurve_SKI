# 여신한도점검

> 상류: 워크플로우 설계도 · Lv4 「석유제품 영업」 · Lv5 「월간 수주·여신 심사」 · Lv6 「여신한도점검」
> Human 여부: 증강 · Skill화 용이성: 중간

## 갈림길
이 태스크의 결과에 따라 다음이 갈린다: 여신조정요청 또는 수주확정품의.

판단기준(원본 흐름도의 ◆): 한도 초과 있음? Yes -> 여신조정요청; No -> 수주확정품의

- 거래처별로 `현재여신 + 이번 달 신규주문 금액`을 여신한도와 견준다.
- 한도를 넘는 거래처가 **1곳이라도 있으면** 여신조정요청으로 보낸다.
- 0곳이면 수주확정품의로 보낸다.

## 판단기준
- 이번 달 주문이 없는 거래처는 판정하지 않는다 — 주문이 없는 것은 초과가 아니다.
- `여신예외승인` 표에 있는 거래처는 한도를 넘어도 **초과로 세지 않고** `예외승인`으로
  표시한다. 다만 승인 근거를 최종 점검표에 남겨 사람이 다시 확인하게 한다.
- 예외승인 표에 **없는** 거래처의 초과는 사유를 지어내지 않고 조정 대상으로 올린다.
- 1원이라도 넘으면 초과로 센다. 임의로 절사하지 않는다.

## 예외
- 여신한도가 비어 있는 거래처는 무한대로 보지 않고 사람에게 넘긴다.
