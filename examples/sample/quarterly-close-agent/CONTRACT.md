# 통합 계약 — 분기/반기 결산

Lv4 「별도/연결 결산관리」 · Lv5 「분기/반기 결산」(원본 P-A2-1)의 Lv6 태스크 7개를 이었다.
갈림길이 있어 경로가 2개다.
루프백: 차이분석조정 ↩ 계정검증대사 (탈출: 차이가 0이 되면)

```contract
tables:
  결산캘린더.csv: 구분, 마감일, 담당부서, 제출기한, 상태
  SAP원장잔액.csv: 계정코드, 계정명, 당기잔액, 전기잔액, 구분
  계열사연결패키지.csv: 계열사코드, 계열사명, 수신여부, 수신일자, 순자산
  전기주석.csv: 주석번호, 주석항목, 전기금액, 설명
  외부확인서.csv: 계정코드, 확인처, 확인잔액, 수신여부, 확인서번호
  잔액수집결과.csv: 계정코드, 계정명, 당기잔액, 전기잔액, 증감률, 이상여부
  조정분개장.csv: 분개번호, 계정코드, 차변, 대변, 사유, 상태
  주석초안.csv: 주석번호, 주석항목, 전기금액, 당기금액, 증감률, 상태
  대사결과.csv: 계정코드, 계정명, 원장잔액, 확인잔액, 차이, 상태, 회차
writers:
  잔액수집결과.csv: 원장잔액수집
  조정분개장.csv: 조정분개작성
  주석초안.csv: 주석초안작성
  대사결과.csv: 계정검증대사
chain: 결산일정수립 -> 원장잔액수집 -> 조정분개작성 -> 주석초안작성 -> 계정검증대사 -> 차이분석조정; 결산일정수립 -> 원장잔액수집 -> 조정분개작성 -> 주석초안작성 -> 계정검증대사 -> 결산마감
payloads: 분기/반기결산입력, 결산일정수립결과, 원장잔액수집결과, 조정분개작성결과, 주석초안작성결과, 계정검증대사결과, 차이분석조정결과, 결산마감결과
threshold: 이상 잔액 ±30% · 주석 설명필요 ±20%
halt_at: 차이분석조정, 결산마감
```

## 갈림길 조건 (계정검증대사)

| 조건 | 다음 |
|---|---|
| 원장잔액 ≠ 확인잔액인 계정이 1건 이상 | 차이분석조정 (→ 조정 후 계정검증대사로 되돌아감) |
| 차이 0건 | 결산마감 |

확인서 미수신 계정은 차이로 세지 않는다 — **차이가 없는 것과 다르다.**

## 루프백 (차이분석조정 ↩ 계정검증대사)

원본 Agent 3이 **L4(차이대사) 루프백**으로 기록한 자리다.
"결산 프로세스(P-A2-1)가 23노드로 최대 규모이며, 2개 루프백이 결산 지연의 주요 원인"

- 탈출 조건: 조정분개를 반영해 재대사했을 때 **차이가 0**
- 회차를 대사결과.csv의 `회차` 칸에 기록한다. 몇 바퀴 돌았는지가 개선 지표다.
