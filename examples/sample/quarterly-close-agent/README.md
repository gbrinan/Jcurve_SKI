# 분기/반기 결산 — 팀 에이전트 (갈림길 + 루프백)

**되돌아가는 흐름이 있는 첫 팩**입니다. 실제 업무는 한 번에 끝나지 않고 반려·재작업으로 돕니다.

- 출처: **AX전략 워크샵 · 재무본부 회계관리팀** (2026-08-18) —
  Workshop Agent 1 → 2-1 → 2-2 → 3 → 4 체인의 산출물에서 옮겼습니다.
- 원본 프로세스: **P-A2-1 분기/반기 결산** (As-Is 23노드, 13개 프로세스 중 최대 규모)
- 산출물 유형: **팀 에이전트 (갈림길·루프백 있음)** — AI 태스크 5개(ATF③) · 갈림길 1곳 + 루프백 1곳(ATF④)

## 왜 루프백이 핵심인가

Agent 3(Process Flow Designer)이 이렇게 적었습니다:

> 결산 프로세스(P-A2-1)가 23노드로 최대 규모이며, **2개 루프백(L3 이상잔액, L4 차이대사)이
> 결산 지연의 주요 원인**

이 팩은 그중 **L4(차이대사) 루프백**을 그대로 옮긴 것입니다. 예전 점검기는 되돌아가는 흐름을
아예 받지 못했습니다 — 변환 단계에서 "시작 태스크가 0개"로 거부됐습니다.

```
결산일정수립[증강] → 원장잔액수집[자동] → 조정분개작성[증강] → 주석초안작성[증강]
                                                                      ↓
                                                          계정검증대사[증강] ◆ 차이 발견?
                                                            ↑            │
                                        ↩ 조정 후 재대사    │            ├─ Yes → 차이분석조정[사람고유]
                                        (차이 0이면 탈출)  └────────────┘
                                                                        └─ No  → 결산마감[사람고유] ⛔
```

## 돌려보기

```bash
python3 examples/sample/quarterly-close-agent/run.py
```

```
[계정검증대사] [1회차] 대사 5계정 · 차이 1건 · 확인서미수신 1건 (차이로 세지 않음)
◆ 차이 발견? → Yes · 차이분석조정으로 분기
[차이분석조정] ⛔ 사람고유 — 차이 1건의 목록과 근거만 만듦 (조정 금액을 정하지 않음)
    · 1110 매출채권 — 원장 8,340,000,000 vs 확인 8,220,000,000 = 차이 120,000,000
    ⏸ 결산담당 확정 대기 …
[차이분석조정] ↩ 계정검증대사로 되돌아감 (탈출 조건: 차이 0)
[계정검증대사] [2회차] 대사 5계정 · 차이 0건
◆ 차이 발견? → No · 결산마감으로 진행 (2회차에 탈출)
```

`대사결과.md`에 **회차**가 쌓입니다. 몇 바퀴 돌았는지가 곧 개선 지표입니다 —
원본 워크샵이 이 루프를 지연 원인으로 지목했기 때문입니다.

## 지어내지 않는 것이 실행에서 보입니다

| 상황 | 에이전트가 한 일 |
|---|---|
| 계열사 2곳 자료 미수신 (PP-6) | 0으로 채우지 않고 합계에서 제외, 미수신으로 표시 |
| 확인서 미수신 계정 | `확인서미수신` — **차이 0과 구분**해서 표시 |
| 조정 사유를 모르는 계정 | `사유확인필요` — 그럴듯한 사유를 만들지 않음 |
| 전기 잔액 0인 계정 | 증감률 계산하지 않고 `신규계정` |

## 실행 화면

`agent-mockup.html`을 브라우저로 엽니다. **▶ 실행**을 누르면 ● 시작부터 한 단계씩 돕니다.

1회차에서 갈라져 되돌아왔다가 2회차에 빠져나가는 장면이 그대로 재생되고,
**차이분석조정에서 멈춥니다** — 사람고유 지점이라 `확인하고 계속 ▶`을 눌러야 다음으로 갑니다.
하단 진행 바가 0에서 100%까지 채워집니다.

숫자는 전부 `out/trace.json`에서 옵니다. 데이터를 고치고 `run.py`를 다시 돌린 뒤
`python3 check/make_mockup.py .`로 화면을 다시 만드십시오.

## 사람이 멈추는 자리

- **차이분석조정** — 결산담당이 조정을 확정할 때까지 멈춥니다. 조정 금액을 대신 정하지 않습니다.
- **결산마감** — 팀장이 점검표를 확인할 때까지 멈춥니다.
  **원장 Lock·마감 전표 코드가 이 팩에 없습니다.**
