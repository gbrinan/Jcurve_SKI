# 계정검증대사

> 상류: T-A2-1-5 「계정 검증 및 대사」 · Human 여부: 증강 · Skill화 용이성: 중간
> 원본 Lv6 Activity: A-A2-1-5-1 외부확인서 수신 및 분류 · A-A2-1-5-2 SAP 원장 잔액과 대사
> Agent 4 To-Be: [🤖] OCR 수신·자동 분류 + 자동 매칭 대사 (OPT-6, 13h/월 절감)

## 갈림길
이 태스크의 결과에 따라 다음이 갈린다: 차이분석조정 또는 결산마감.

판단기준(원본 흐름도의 ◆): 차이 발견? Yes -> 차이분석조정; No -> 결산마감

- 결산데이터.md의 확인 잔액과 SAP 원장 잔액을 계정별로 맞춘다.
- 차이가 **1건이라도 있으면** 차이분석조정으로 보낸다.
- 차이가 0건이면 결산마감으로 보낸다.

## 판단기준
- 대사 대상은 결산데이터.md에 확인서가 있는 계정만이다. 확인서 없는 계정은 대사하지 않는다.
- 차이 금액이 1원이라도 나면 차이로 센다. 임의 절사하지 않는다.
- 확인서 미수신 계정은 `확인서미수신`으로 표시하고 차이로 세지 않는다 — 차이가 없는 것과 다르다.

## 예외
- 같은 계정에 확인서가 둘 이상이면 합산하지 않고 `확인서중복`으로 표시해 사람에게 넘긴다.
