# 원장잔액수집

> 상류: T-A2-1-2 「계정별 잔액 확인」 · Human 여부: 자동 · Skill화 용이성: 높음
> 원본 Lv6 Activity: A-A2-1-2-1 SAP 원장 잔액 추출 · A-A2-1-2-2 계열사 데이터 수신 확인 ·
> A-A2-1-2-3 이상 잔액 식별 및 원인 파악
> Agent 4 To-Be: 세 Activity 모두 [🤖] 자동화 대상

## 판단기준
- 결산데이터.md에서 계정별 당기·전기 잔액을 읽는다.
- 결산데이터.md에서 수신 여부를 확인한다. **미수신 계열사는 미수신으로 남긴다.**
- 이상 잔액: 전기 대비 증감률이 ±30%를 넘거나 부호가 뒤집힌 계정을 표시한다.

## 예외
- 계열사 자료가 미수신이면 그 계열사 몫을 0으로 채우지 않는다. 합계에서 제외하고 미수신으로 표시한다.
- 전기 잔액이 0이면 증감률을 계산하지 않는다(0으로 나누지 않는다). `신규계정`으로 표시한다.

## 관련 Pain Point
- **PP-6 [WAIT/높음]** 연결결산 계열사 자료 수신 지연 — 수신 지연·품질 편차로 결산 일정 차질.
  이 스킬은 지연을 없애지 못한다. **어느 계열사가 아직인지**를 즉시 드러낸다.
