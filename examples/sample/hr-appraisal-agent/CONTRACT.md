# 통합 계약 (워크플로우 설계도 변환 초안)

Lv4 「평가·보상」 · Lv5 「연간 성과평가 운영」의 Lv6 태스크 6개를 이었다. 갈림길이 있어 경로가 2개다.
루프백: 이상조직조정요청 ↩ 리더평가입력점검 (탈출: 조정 후 재검증한다. 분포가 가이드라인 안에 들어오면 반복이 끝난다)

```contract
tables:
  평가데이터.md: 평가일정 / 평가대상자 / 자기평가제출 / 리더평가입력 / 등급분포가이드라인 / 근거요구등급 (6개 표)
  자기평가취합결과.md: 사번, 성명, 조직, 제출여부, 제출일, 상태
  리더평가점검결과.md: 사번, 성명, 조직, 평가리더, 등급, 근거기재, 점검결과
  분포검증결과.md: 조직, 인원, 등급, 인원수, 비율, 허용상한, 판정
writers:
  자기평가취합결과.md: 자기평가취합
  리더평가점검결과.md: 리더평가입력점검
  분포검증결과.md: 평가정합성검증
chain: 평가계획수립 -> 자기평가취합 -> 리더평가입력점검 -> 평가정합성검증 -> 이상조직조정요청; 평가계획수립 -> 자기평가취합 -> 리더평가입력점검 -> 평가정합성검증 -> 등급확정통보
payloads: 연간성과평가운영입력, 평가계획수립결과, 자기평가취합결과, 리더평가입력점검결과, 평가정합성검증결과, 이상조직조정요청결과, 등급확정통보결과
threshold: 등급 허용상한 S 15% · A 40% · B 60% · C 20% · D 10% (조직 단위)
halt_at: 이상조직조정요청, 등급확정통보
```

## 갈림길 조건 (평가정합성검증)

| 조건 | 다음 |
|---|---|
| 조직별 등급 비율이 허용상한을 넘는 것이 1건 이상 | 이상조직조정요청 (→ 조정 후 리더평가입력점검으로 되돌아감) |
| 상한초과 0건 | 등급확정통보 |

분모는 **등급이 입력된 인원**이다. 미입력자는 분모에서 제외한다 —
입력이 없는 것과 낮은 등급은 다르다.

## 루프백 (이상조직조정요청 ↩ 리더평가입력점검)

- 탈출 조건: 조정을 반영해 재검증했을 때 **분포 이상이 0**
- 5회차까지 이상이 남으면 반복을 멈추고 사람에게 넘긴다 — 무한히 돌지 않는다.
- 회차마다 다시 점검하므로, 조정으로 새로 생긴 근거미기재도 함께 잡힌다.
