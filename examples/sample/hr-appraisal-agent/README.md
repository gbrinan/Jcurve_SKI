# 연간 성과평가 운영 — 팀 에이전트 (갈림길 + 루프백)

**HR 사례**입니다. 재무 팩(분기/반기 결산)과 같은 구조를 인사 업무로 옮겼습니다 —
갈림길에서 갈라지고, 조정하러 되돌아갔다가, 사람 앞에서 멈춥니다.

- 출처: **AX전략 워크샵 · 인사본부 인사운영팀** — 워크플로우 설계도에서 옮겼습니다.
- 원본 프로세스: **P-B2-1 연간 성과평가 운영**
- 산출물 유형: **팀 에이전트 (갈림길·루프백 있음)** — AI 태스크 4개(ATF③) · 갈림길 1곳 + 루프백 1곳(ATF④)

## 흐름

```
평가계획수립[자동] → 자기평가취합[자동] → 리더평가입력점검[증강]
                                              ↑            ↓
                        ↩ 조정 후 재점검      │    평가정합성검증[증강] ◆ 분포 이상 있음?
                        (분포 이상 0이면 탈출) │            │
                                              └────────────┼─ Yes → 이상조직조정요청[사람고유]
                                                           └─ No  → 등급확정통보[사람고유] ⛔
```

## 돌려보기

```bash
python3 examples/sample/hr-appraisal-agent/run.py
```

```
[자기평가취합] 제출 32/33명 · 미제출 1명 (제출로 채우지 않음) · 지각제출 1명
[리더평가입력점검] [1회차] 입력 32/33명 · 미입력 1명 (분포 계산에서 제외) · 근거미기재 1명 (S·D등급)
[평가정합성검증] [1회차] 조직 4개 검증 · 분포 이상 1건 (공정개선팀)
◆ 분포 이상 있음? → Yes · 이상조직조정요청으로 분기
[이상조직조정요청] ⛔ 사람고유 — 이상 1건의 목록과 근거만 만듦 (누구의 등급을 내릴지 정하지 않음)
    · 공정개선팀 S등급 2/8명 = 25.0% (상한 15%)
    ⏸ 조직책임자 조정 대기 …
[이상조직조정요청] ↩ 리더평가입력점검으로 되돌아감 (탈출 조건: 분포 이상 0)
[평가정합성검증] [2회차] 조직 4개 검증 · 분포 이상 0건
◆ 분포 이상 있음? → No · 등급확정통보로 진행 (2회차에 탈출)
[등급확정통보] ⛔ 사람고유 — 점검표 4건만 만들고 멈춤
```

## 지어내지 않는 것이 실행에서 보입니다

| 상황 | 에이전트가 한 일 |
|---|---|
| 휴직자 1명 자기평가 미제출 | 제출로 채우지 않고 `미제출`로 남김 — **없는 것과 있는 것은 다름** |
| 리더가 등급을 아직 안 넣음 (1명) | B로 채우지 않고 `미입력` · **분포 계산의 분모에서 제외** |
| S등급인데 근거 미기재 (1명) | `근거미기재`로 표시하되 **등급은 바꾸지 않음** |
| 분포 상한 초과 조직 | 목록·근거만 만들고 **누구를 내릴지는 정하지 않음** |
| 마감 후 제출 (1명) | 제출은 제출로 세되 `지각제출`로 구분 |

## 실행 화면

`agent-mockup.html`을 브라우저로 엽니다. **▶ 실행**을 누르면 ● 시작부터 한 단계씩 돕니다.
하단 실행 로그가 흐르고, 진행 바가 0에서 100%까지 채워집니다.

1회차에서 갈라져 되돌아왔다가 2회차에 빠져나가는 장면이 그대로 재생되고,
**이상조직조정요청에서 멈춥니다** — 사람고유 지점이라 `확인하고 계속 ▶`을 눌러야 다음으로 갑니다.

숫자는 전부 `out/trace.json`에서 옵니다. 데이터를 고치고 `run.py`를 다시 돌린 뒤
`python3 check/make_mockup.py .`로 화면을 다시 만드십시오.

## 사람이 멈추는 자리

- **이상조직조정요청** — 조직책임자가 조정을 확정할 때까지 멈춥니다.
  **누구의 등급을 내릴지 대신 정하지 않습니다.**
- **등급확정통보** — 인사담당 임원이 점검표를 확인할 때까지 멈춥니다.
  **등급 확정·통보 코드가 이 팩에 없습니다.**

## 데이터

`data/평가데이터.md` **한 파일**에 표 6개가 들어 있습니다. 전부 **실습용 가상 값**이고,
사번·성명·조직·등급 모두 실재하지 않습니다. 실도입 전에 HR ERP·평가시스템 데이터로 교체합니다.

표마다 왜 그 값인지가 문장으로 붙어 있습니다. 값을 고쳐서 다시 돌려보십시오:

| 고칠 것 | 일어나는 일 |
|---|---|
| 리더평가입력의 `E-2002` 등급 → `A` | 분포 이상이 사라져 **루프백 없이 1회차에 등급확정통보** |
| 등급분포가이드라인의 S 허용상한 → `30%` | 같은 결과 — 상한이 올라가 이상이 사라짐 |
| 리더평가입력의 `E-2001` 근거기재 → `기재` | 근거미기재가 **1건 → 0건**, 최종 점검표 4건 → 3건 |
