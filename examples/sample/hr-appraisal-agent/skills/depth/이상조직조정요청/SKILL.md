# 이상조직조정요청

> 상류: 워크플로우 설계도 · Lv4 「평가·보상」 · Lv5 「연간 성과평가 운영」 · Lv6 「이상조직조정요청」
> Human 여부: 사람고유 · Skill화 용이성: 낮음

## 갈림길
이 태스크의 결과에 따라 다음이 갈린다: 리더평가입력점검(루프백).
판단기준(원본 흐름도의 ◆): 조정 후 재검증한다. 분포가 가이드라인 안에 들어오면 반복이 끝난다

## 되돌아가기 (루프백)
- 이 태스크에서 리더평가입력점검(으)로 되돌아간다 — 조정·재점검 흐름.
- 반복이 끝나는 조건: 분포 이상이 0이 되면 끝난다.
- 5회차까지 이상이 남으면 반복을 멈추고 사람에게 넘긴다 — 무한히 돌지 않는다.

## 판단기준
- 상한을 넘은 조직·등급의 **목록과 근거(비율·상한·인원)만** 만든다.
- **누구의 등급을 내릴지 정하지 않는다.** 조정 대상자 선정은 조직책임자의 판단이다.

## 사람이 확인하고 멈추는 지점
- 이상조직조정요청 — 사람이 직접 판단한다. 자동으로 진행하지 않는다.
- 조정이 확정되었다고 사람이 알려주기 전에는 되돌아가지 않는다.
