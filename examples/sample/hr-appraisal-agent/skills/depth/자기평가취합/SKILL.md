# 자기평가취합

> 상류: 워크플로우 설계도 · Lv4 「평가·보상」 · Lv5 「연간 성과평가 운영」 · Lv6 「자기평가취합」
> Human 여부: 자동 · Skill화 용이성: 높음

## 판단기준
- `자기평가제출` 표의 제출여부를 대상자 명단에 맞춰 집계한다.
- 제출여부가 `제출`이 아니면 `미제출`로 남긴다. **제출로 채우지 않는다** —
  제출하지 않은 것과 제출한 것은 다르다.
- 제출일이 마감일(2026-11-20)보다 늦으면 `지각제출`로 표시한다. 제출은 제출로 센다.

## 예외
- 미제출 사유는 데이터의 `비고` 칸에 적힌 것만 쓴다. 사유를 추측해 적지 않는다.
- 명단에 있으나 제출 표에 없는 사람은 `미제출`로 본다.
