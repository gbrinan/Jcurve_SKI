# 리더평가입력점검

> 상류: 워크플로우 설계도 · Lv4 「평가·보상」 · Lv5 「연간 성과평가 운영」 · Lv6 「리더평가입력점검」
> Human 여부: 증강 · Skill화 용이성: 중간

## 판단기준
- `리더평가입력` 표에서 등급이 비어 있으면 `미입력`으로 표시하고,
  **분포 계산에서 제외**한다. B로 채우지 않는다 — 입력이 없는 것과 낮은 등급은 다르다.
- `근거요구등급` 표에서 근거필수인 등급(S·D)인데 근거기재가 `기재`가 아니면
  `근거미기재`로 표시한다.
- **등급을 바꾸지 않는다.** 점검까지다. 등급 조정은 조직책임자가 한다.

## 예외
- 조정이 확정되어 되돌아온 경우(루프백), 확정된 등급을 반영해 다시 점검한다.
  조정 내역은 사람이 정한 것만 반영하고, 누구를 조정할지 이 스킬이 정하지 않는다.
