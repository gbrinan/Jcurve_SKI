# 이 팩을 어떻게 읽었는가 (readchk)

> 작업을 시작하기 전에 남기는 기록입니다. 나중에 읽는 사람이 "이 팩이 의도대로 만들어졌는지"를 이 문서와 대조해 확인할 수 있습니다.

## 이해한 바

- 출처 업무: Lv4 「평가·보상」 › Lv5 「연간 성과평가 운영」
- 스킬 6개를 갈림길·루프백이 있는 흐름으로 이었다: 평가계획수립 → 자기평가취합 → 리더평가입력점검 → 평가정합성검증 → 이상조직조정요청 · 이상조직조정요청 ↩ 리더평가입력점검
- AI가 맡는 태스크 4개, 사람이 직접 하는 태스크 2개 (등급확정통보, 이상조직조정요청)
- 산출물 유형: 팀 에이전트(갈림길·루프백 있음)
- 흐름의 끝: 등급확정통보, 이상조직조정요청

## 아직 정해지지 않은 것

### ① 가장 먼저 정할 것 — 데이터 명세

**무엇이 문제인가**: 표 이름과 칸 이름이 아직 없습니다. 설계도 단계에는 데이터 정보가 없어서 인터뷰에서 채워야 합니다.

**왜 이것부터인가**: 표·칸 이름이 아직 없다

**선택지**

1. 팀이 실제로 쓰는 엑셀/시트 이름부터 받아 채운다
2. 실습용 가상 값으로 채우고 실도입 전 교체한다

> 이 결정은 **기본값으로 채우지 않았습니다.** 팀이 고른 뒤 이 문서에 답을 적으십시오.

### 그 밖에 (①을 정한 뒤 순서대로)

- **연동 맵** — 다른 스킬·에이전트와 붙는지 아직 정해지지 않았습니다.
