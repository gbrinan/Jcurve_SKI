목표와 산출물

오늘 세션에서 만드는 것

  • 공용 드라이브에 Lv.6 스킬을 팀 Lv.5로 통합·패키징
  • 팀원 전원이 동일한 파일을 마운트해 같은 것을 본다
  • 전체 프로세스를 관통하는 동작 테스트 — 검증 지점·휴먼인더루프 점검
  • 산출물: 스킬팩·폴더 트리 + 동작하는 Lv.5 에이전트(MVP) + 기획서
설계 철학 · paperthin

더하지 말고, 덜어낸다

  • 제거 우선 — 겹치는 스킬은 합치고, 답 못 하는 항목은 뺀다
  • SSOT — 모든 표·파일의 원본은 단 한 곳, 나머지는 참조
  • 재작성(re0) — 스킬 3개를 이어붙이지 않고 팀 관점의 v0으로
  • 경계 명시 — 자동으로 할 일 vs 사람이 확인할 일을 처음부터 구분
  • 다관점 검증 — 만들지 않은 팀원의 눈으로 "이게 정말 맞나?"
진행 방식

인터뷰 6문항 — AI 코치가 한 번에 하나씩

#질문확정되는 것
1우리는 어떤 팀인가미션 · 줄여줄 반복 업무
2스킬의 역할은핵심 역할 한 문장 (중복 제거)
3어떤 데이터를 쓰는가표·칸 이름 + 원본 위치(SSOT)
4사용 시나리오 1개트리거 → 입력 → 처리 → 출력
5결과는 어디에 반영기록될 표·칸 (3번과 연결)
6다른 스킬과 연동인터페이스 또는 "현재는 독립"

객관식(A~D + 기타) · 답마다 확정 요약 → 완료 시 기획서(agent-plan.md) 자동 생성
